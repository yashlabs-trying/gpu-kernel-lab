# Llama GPU acceptance — RTX A4000 — 2026-10-01

This is a factual summary of artifacts stored on the acceptance host under
`results/llama_gpu_a4000_20261001/`. It is not a release declaration.
The 23-file, 491 MB raw artifact set is covered by `SHA256SUMS`; that manifest's
SHA-256 is `439d7c72bb9252cf09d3042ffc2a23d60e15347c6ee19d5d4c1b359e52c07868`.

## Environment and model integrity

- NVIDIA RTX A4000, 16,376 MiB, compute capability 8.6
- Driver 580.126.20; PyTorch 2.9.0+cu128; CUDA runtime 12.8
- Transformers 4.57.6; vLLM 0.13.0
- Llama 3.2 3B FP16 converted from GGUF source SHA-256

- All converted checkpoint checksums passed, 3.213B parameters loaded, and the
  CUDA smoke generation completed correctly.

## Cold start and mixed-length serving

The vLLM server used FP16, a 9,216-token maximum context, four active sequences,
95% GPU-memory utilization, and prefix caching disabled.

- Process start to `/health`: 71.264 seconds
- Process start to `/v1/models`: 71.267 seconds
- Shutdown after the measurement was graceful.
- The mixed workload submitted 100 short 128-token prompts and 100 long
  8,192-token prompts, each requesting 128 output tokens, at concurrency 4.
- All 200 requests succeeded in 272.04 seconds with 94.10 output tok/s.
- Short-request p99: 2,347.63 ms TTFT and 6,841.39 ms end to end.
- Long-request p99: 2,722.55 ms TTFT and 8,562.09 ms end to end.
- Long-to-short p99 end-to-end ratio: 1.252x.

## Full deterministic FP16 versus INT8 quality gate

Both captures used all 12 checked-in multi-domain prompts, 32 generated tokens
per prompt, full 128,256-vocabulary logits, and all 29 hidden-state layers.

- Generated-token and final-logit argmax agreement: 52.60%.
- Logit cosine: 0.78134 mean and -0.40706 minimum.
- Maximum absolute logit difference: 30.834.
- Reference NLL/perplexity: 0.61963 / 1.8582.
- INT8 NLL/perplexity on FP16 reference tokens: 6.08199 / 437.902.

## Kernel evidence

- Runtime shapes were exported for every layer and projection.
- In the single-stream PyTorch decode profile, the top CUDA kernels were GEMV
  (41.06%), CUTLASS FP16 GEMM (32.19%), and transposed GEMV (9.82%). Flash
  attention accounted for less than 1% of captured CUDA time.
- The local standalone and fused-residual RMSNorm candidates were numerically
  close but slower than vLLM's active operation at every measured shape from 1
  through 2,048 rows. Best median ratios versus vLLM were 0.890x for standalone
  and 0.828x for fused residual; no candidate is eligible for integration.
- Nsight Compute remains unavailable for useful counters in this RunPod
  container, and no Docker or Podman runtime is installed for a container build.

## Reliability soak

The formal one-hour soak used concurrency 16 with 128 input and 128 output
tokens per request. The server was configured for four active sequences, so the
measurement includes production-style queueing rather than unconstrained KV
allocation on the 16 GB GPU.

- 5,872/5,872 requests succeeded; error rate was 0%.
- The measured wall time was 3,606.58 seconds.
- Output throughput was 208.40 tok/s (751,616 output tokens).
- p99 TTFT was 7,446.75 ms, p99 ITL was 19.35 ms, and p99 end-to-end latency
  was 9,819.82 ms.
- The server remained healthy afterward with zero running and zero waiting
  requests; the generation counter reached 753,664 including warmups.
- During sampled steady state, utilization was 96–98%, memory was about
  15.4/16.4 GB, board power was about 139–140 W, and temperature stabilized at
  85–86°C. No OOM, traceback, server restart, or throughput collapse occurred.

## Remaining release blockers

- A4000 and A5000 are both Ampere (compute capability 8.6), so a second GPU
  architecture still needs validation.
- CUDA 13.0 needs its own reproducible artifact set.
- TP2/TP4 scaling, communication overhead, and worker recovery require a
  multi-GPU host.
- Container build and GPU smoke testing require a host with Docker or Podman.
- The local RMSNorm candidate is rejected on performance, and no original
  kernel has yet beaten the active vLLM operation end to end.
