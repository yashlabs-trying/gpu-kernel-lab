# Llama GPU acceptance — RTX A5000 — 2026-09-30

This is a factual summary of the schema-v2 artifacts stored on the acceptance
host under `results/llama_gpu_a5000_20260930/`. It is not a release declaration.

## Environment

- NVIDIA RTX A5000, 24,564 MiB, compute capability 8.6
- Driver 580.159.04; PyTorch 2.9.0+cu128; CUDA runtime 12.8
- Transformers 4.57.6; vLLM 0.13.0
- Llama 3.2 3B FP16 converted from GGUF source SHA-256
  `bce7f0f4ece276bc08411b062c851e8b2b259caec11ab1ae0dc3f5555dfe76b1`
- Converted checkpoint checksum verification and CUDA generation passed.
- vLLM selected FlashAttention and completed CUDA Graph capture.

## Quality and reliability

- FP16 and BitsAndBytes INT8 captures contain 16 generated tokens, full logits,
  and every layer's hidden state.
- INT8 has 100% generated-token and final-logit argmax agreement on the captured
  prompt, but fails the release gate: minimum logit cosine 0.995914 (required
  0.999) and NLL 0.760732 versus FP16 0.737077. INT8 is therefore not promoted.
- Cancellation: 20/20 requests reached first token and were then cancelled;
  health recovered.
- Overload: 1,000/1,000 requests succeeded at c128, 936.70 output tok/s, with
  the server healthy afterward.
- A five-minute c32 soak was run as an accelerated stability check. It does not
  satisfy the formal one-hour release gate. It completed 8,576/8,576 requests,
  914.57 output tok/s, and returned to zero running/zero waiting requests.
- Streaming completions emitted valid SSE chunks and `[DONE]`.
- The bundled Llama 3 template made `/v1/chat/completions` return HTTP 200. The
  base checkpoint did not follow a simple chat instruction, so production chat
  quality requires instruct weights.

## Still blocking a production release

- One-hour soak, external LM evaluation, and the broader multi-prompt quality
  corpus have not passed yet.
- CUDA 13.0 and a second reproducible GPU artifact set remain to be validated.
- Tensor-parallel scaling requires a multi-GPU host.
- Original Llama kernel candidates must be implemented and must beat the active
  vLLM path end to end before they can be accepted.
